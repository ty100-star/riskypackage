# Risky Package

Risky Package is a first-person platformer and obstacle course game
where players attempt to deliver packages to houses while avoiding
dangerous obstacles.

## Gameplay

The player must deliver packages to houses while navigating through
a colorful, low-poly neighborhood filled with obstacles.

The goal is to:
- Deliver all packages before time runs out.
- Avoid obstacles and protect your health.
- Complete each delivery to continue to the next house.

## Win Condition

Deliver all packages before the timer runs out without losing all health.

## Lose Condition

The player loses if they run out of time or lose all of their health
before delivering all of the packages.

## Features

- First-person gameplay
- Physics and obstacle-based challenges
- Randomized obstacles
- Health system
- Package delivery system
- Colorful low-poly environment
